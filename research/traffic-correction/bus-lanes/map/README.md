# Карта слоя и трёх поисков

Открыть `index.html` — полностью автономная HTML-карта со встроенным SVG. Для просмотра и передачи отдельно: `coverage-and-three-routes.png` и векторный `coverage-and-three-routes.svg`.

Показан первый возвращённый автобусный вариант каждого из трёх сохранённых поисков: 74, 40 и 39Э. Это не сумма всех альтернатив и не утверждение, что именно эти варианты всегда будут первыми. Другие варианты и совпавшие после перепланирования хвостов маршруты не дублируются на карте.

- Зелёный фон: явные направленные OSM-полосы; 433 направленных представления во всём извлечении, не 433 независимых физических полосы.
- Фиолетовый / оранжевый / синий: фактическая геометрия автобусного варианта. Серые точки: пешая часть.
- Тёмно-зелёный: точный частичный защищённый интервал на геометрии GTFS. На 74 он составляет 13.826 м; на выбранных 40 и 39Э подтверждённых интервалов нет.
- Красный пунктир: остаток без пригодного покрытия трафиком и без подтверждённой полосы. Это неизвестность, а не доказательство отсутствия полосы.

**34 из 37** записей реестра имеют независимые свидетельства OSM на той же улице; один официальный коридор — Малая Морская — теперь разрешён по точным границам и показан пурпурным. Финальный профиль содержит 674 пары GTFS / 1699 вариантов. Геометрия трёх сохранённых live-ответов получена с предыдущим слоем 672/1695; поздний геослой не выдаётся за результат новых запросов.

`route-map-data.json` содержит использованные геометрии. Интервалы восстановлены из сохранённых debug-полей через `TrafficGraph.trip_segments` и `slice_line`; полные OSM way не выдаются за точные защищённые участки маршрута. `inputs.json` фиксирует хеши входов. OSM timestamp — дата изменения объекта, не дата наблюдения дорожных знаков.

Воспроизведение из корня проекта: `backend/.venv/bin/python research/traffic-correction/bus-lanes/map/build_data.py`, затем `python research/traffic-correction/bus-lanes/map/render_map.py`. Первый шаг требует локального GTFS-индекса по пути, записанному в скрипте; второй использует сохранённую подложку `background-roads.json` и matplotlib. Внешние тайлы, геокодеры и API не используются. Подложка взята из локального `spb-lo.osm.pbf`: © OpenStreetMap contributors, ODbL.
